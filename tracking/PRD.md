# PRD - ACNU Cinematic Landing

## Project Vision
Create a "One Million Dollar" rendering cinematic website for the Association Camerounaise pour les Nations Unies (ACNU). The site must feature a dynamic "Theme Matrix" allowing the user to toggle between three distinct visual angles: Diplomatic Elite, Organic Citizen, and Kinetic Youth.

## Key Technical Requirements
- **Framework**: React 19 + Vite.
- **Styling**: Tailwind CSS v4 (Integrated with `@tailwindcss/vite`).
- **Animations**: GSAP 3 + ScrollTrigger for weighted, intentional cinematic transitions.
- **Interaction**: Custom Theme Switcher panel (Director Mode).
- **Core Sections**:
  - Navbar (Floating Island)
  - Hero (Opening Shot)
  - Features (Diagnostic Shuffler, Telemetry Typewriter, Protocol Scheduler)
  - Philosophy (Manifesto parallax reveal)
  - Protocol (Sticky Stacking Archive)
  - Membership & Footer
  - Member Search Widget

## Aesthetic Pillars
- High contrast typography (Large Serifs vs Modern Sans).
- Global noise overlay for textured cinematic feel.
- Dynamic image filtering based on active theme.
- Responsive design tailored for frontier-level UX.
